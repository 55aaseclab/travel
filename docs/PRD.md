# Travel 产品需求

双语行程阅读器，提供路线目录、每日计划、预算、准备清单及可选的地图和地点搜索。新安装的路线目录为空。私有路线资料可独立生成浏览页，经授权的业务操作可更新配置的行程。

应用具有独立入口，工作数据存放在源码目录外。接入工作台时沿用相同的视图。

受管共享攻略空间可以在未登记任何行程时启动，返回空的已授权列表与原生目录，应用入口仍可使用。空白启动不创建行程记录。之后可由获授权的运维流程提供来源目录、在私有空间映射中登记行程标识并重启服务，既有记录及范围校验继续有效。

## Praxis 供数接口

应用通过版本 1 的 `praxis-provider.mjs` 提供有来源依据的工作台卡片与数据源描述。读取使用宿主提供的已授权回调，供数模块不直接访问文件、凭据或网络。保留原生对象入口、真实版本或稳定内容摘要，明确区分空态、部分失败与不可用。个人卡片处理不修改共享业务记录。参见[供数合同](PRAXIS-PROVIDER.md)。

## 应用自有 Praxis 集成

本应用在所属仓库维护经审核的 `praxis-integration.mjs`，声明原生入口策略，以及已支持的类型明确的业务操作与 MCP 指引。Praxis 从已安装源码加载声明，继续统一执行授权、签名、策略租约与审计。安装声明不会授予访问权限，也不会启动后端；已有原生界面、数据归属与恢复边界继续生效。
